    Decisiones: condicionales y lógica booleana¶

    Expresiones booleanas¶

    Una condición es una expresión cuyo resultado es True o False.

    Operadores relacionales¶

    Operador Significado Ejemplo Resultado
    == Igual 5 == 5 True
    != Distinto 5 != 3 True
    < / > Menor / mayor 3 < 5 True
    <= / >= Menor o igual / mayor o igual 5 >= 6 False

    Hay que tenerlo claro

    ¡Cuidado! = asigna y == compara.

    Python permite encadenar comparaciones: 0 <= nota <= 10 (en Java habría que escribir nota >= 0 && nota <= 10).

    Operadores lógicos¶

    Operador Significado Java
    and Las dos condiciones son verdaderas &&
    or Al menos una es verdadera \|\|
    not Invierte el valor !

    Tablas de verdad¶

    A B A and B A or B not A
    True True True True False
    True False False True False
    False True False True True
    False False False False True

    Ejemplo: ¿puede entrar en la biblioteca?

    tiene_carnet = True
es_horario = False
print(tiene_carnet and es_horario)   # False

    La sentencia if¶

    nota = float(input("Nota: "))

if nota >= 5:
    print("Aprobado")
    • Los dos puntos : al final de la condición son obligatorios.
    • El bloque se marca con sangría (4 espacios). Todo lo sangrado pertenece al if.

    if … else¶

    if nota >= 5:
    print("Aprobado")
else:
    print("Suspenso")

    if … elif … else (varias opciones)¶

    if nota < 5:
    print("Insuficiente")
elif nota < 7:
    print("Aprobado")
elif nota < 9:
    print("Notable")
else:
    print("Sobresaliente")

    Python comprueba las condiciones en orden y ejecuta solo el primer bloque cuya condición sea cierta. Por eso en el segundo elif no hace falta poner nota >= 7.

    Condicionales anidados¶

    edad = int(input("Edad: "))
if edad >= 18:
    carnet = input("¿Tienes carnet? (s/n) ")
    if carnet == "s":
        print("Puedes conducir")
    else:
        print("Necesitas el carnet")
else:
    print("Eres menor de edad")

    Muchos anidamientos se pueden simplificar con and. Regla práctica: si hay más de 2 niveles, intenta simplificar.

    La sentencia match (Python 3.10 o superior)¶

    Útil cuando se compara una misma variable con varios valores concretos (como el switch de Java):

    dia = input("Día de la semana: ").lower()

match dia:
    case "sábado" | "domingo":
        print("Fin de semana")
    case "lunes" | "martes" | "miércoles" | "jueves" | "viernes":
        print("Día lectivo")
    case _:
        print("Día no válido")

    case _ recoge cualquier otro valor (como default en Java). Comprueba la versión con python3 --version.

    Valores límite: dónde fallan los programas¶

    Si una condición es nota >= 5, los casos más importantes son 4.99, 5 y 5.01. Un programa con nota > 5 funcionaría bien con 3 y con 8, pero fallaría con exactamente 5.

    Para cada reto, la tabla de casos de prueba debe incluir:

    • Un caso normal de cada rama (if, cada elif, else).
    • Los valores límite de cada condición.
    • Al menos un caso no válido (nota 11, edad negativa…).
    | Caso | Entrada | Rama esperada | Salida esperada | Salida obtenida | ¿OK? |

    Actividades¶

    • AC 212(). Par o impar.
    INICIO → LEER n → ¿n % 2 == 0? → Sí: MOSTRAR "par" / No: MOSTRAR "impar" → FIN

    • AC 213(). División segura Pide dos números. Si el divisor es 0, muestra un aviso; si no, muestra el cociente.

    • AC 214(). Mayor de tres. Pide tres números y muestra el mayor sin usar max().

    • AC 215(). Menú de cafetería con `match. Muestra un menú (1. Café, 2. Té, 3. Zumo), pide una opción y muestra el precio. Cualquier otra opción: «Opción no válida».

    • PR 216. Un parking cobra así: la primera hora es gratis; de la 2.ª a la 4.ª hora, 1,50 € cada hora; a partir de la 5.ª hora, 1 € cada hora. Hay un máximo diario de 12 €. Las fracciones de hora se cobran como hora completa. El programa pide los minutos de estancia y muestra el importe.

      Pistas:

      • Descompón: minutos → horas cobrables (redondeando hacia arriba) → importe por tramos → aplicar máximo.
      • Para redondear hacia arriba sin librerías: horas = (minutos + 59) // 60.
      • Casos límite: 60 min, 61 min, 240 min, 241 min, y una estancia larga que supere el máximo.
      Minutos Horas cobrables Importe esperado
      45 1 0.00 €
      61 2 1.50 €
      240 4 4.50 €
      300 5 5.50 €
      900 15 12.00 € (máximo)

    • PR 217. Un año es bisiesto si es divisible entre 4, excepto los divisibles entre 100, que solo lo son si también son divisibles entre 400.

      • Resuélvelo dos veces: primero con if anidados y después con una sola condición usando and, or y not. Comprueba que las dos versiones dan lo mismo.
      • Casos obligatorios: 2024, 2025, 1900, 2000.

    • PR 218. Pide una nota numérica y muestra su calificación: Insuficiente (0 a menos de 5), Suficiente (5 a menos de 6), Bien (6 a menos de 7), Notable (7 a menos de 9), Sobresaliente (9 a 10). Si la nota no está entre 0 y 10, muestra «Nota no válida».

      • Casos límite: 4.99, 5, 5.99, 6, 6.99, 7, 8.99, 9, 10, y -1 y 10.5 como no válidos.
      • Pregunta: ¿importa el orden de los elif? Prueba a cambiarlos.
