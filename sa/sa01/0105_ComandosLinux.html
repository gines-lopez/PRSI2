    Comandos Linux¶

    Qué es la consola y cómo se escribe una orden¶

    La terminal es la ventana; la shell (en LliureX, Bash) es el programa que interpreta lo que escribes. Un administrador trabaja aquí porque es más rápido, funciona en servidores sin escritorio y se puede automatizar.

    Toda orden sigue la misma estructura:

    orden   opciones   argumentos
ls      -l -a      /etc

    El prompt te dice quién eres: usuario@equipo:~$. Si termina en #, eres root: cuidado.

    Si no sabes algo, pregúntale al sistema:

    Orden Para qué
    man ls Manual completo (q para salir, / para buscar)
    ls --help Resumen rápido

    Atajos que ahorran horas

    • Tab autocompleta
    • ↑ repite órdenes anteriores
    • Ctrl+C cancela
    • Ctrl+L limpia la pantalla.

    El árbol de directorios¶

    En Linux no hay C:. Todo cuelga de una raíz, /:

    Directorio Qué hay
    /home Las carpetas de los usuarios
    /etc La configuración del sistema
    /var/log Los registros (logs)
    /tmp Temporales
    /usr/bin Los programas

    Rutas:

    • Absoluta: empieza en / → /home/ana/documentos
    • Relativa: desde donde estás → documentos
    • Atajos: ~ tu carpeta personal
    • . aquí
    • .. la carpeta de arriba
    Orden Hace
    pwd Dónde estoy
    cd ruta Ir a una carpeta
    ls -la Listar todo, con detalles y ocultos

    Ficheros y directorios¶

    Orden Hace
    mkdir -p a/b Crear carpetas
    touch f.txt Crear un fichero vacío
    cp origen destino Copiar (-r para carpetas)
    mv origen destino Mover o renombrar
    rm fichero Borrar (-r para carpetas)
    cat, less, head, tail Ver contenido
    find / -name "*.conf" Buscar ficheros
    grep texto fichero Buscar dentro de ficheros

    Comodines:

    • * cualquier cosa
    • ? un carácter
    • {1..5} genera 1 2 3 4 5.

    Cuidado

    rm -rf borra sin preguntar y para siempre.

    Usuarios y permisos¶

    Cada fichero tiene un propietario, un grupo y unos permisos:

    -rwxr-x---  ana  clase  script.sh
 └┬┘└┬┘└┬┘
  │  │  └ otros
  │  └─── grupo
  └────── propietario

    ¿Qué quiere decir?

    • r leer (4)
    • w escribir (2)
    • x ejecutar o entrar (1)

    Se suman por grupo: rwx = 7, r-x = 5, --- = 0 → 750.

    Orden Hace
    chmod 750 f Cambiar permisos
    chown ana:clase f Cambiar propietario y grupo
    sudo orden Ejecutar como administrador
    adduser nombre Crear usuario
    usermod -aG grupo usuario Añadir a un grupo (¡sin la a le quitas los demás!)

    Redirecciones y tuberías¶

    La salida de una orden puede ir a un fichero o a otra orden:

    Símbolo Hace
    > Guarda en un fichero (lo sobrescribe)
    >> Añade al final del fichero
    2> Guarda solo los errores
    \| Pasa la salida a la siguiente orden

    Con la tubería se construyen órdenes potentes juntando piezas simples:

    cat acceso.log | grep FAIL | wc -l      # ¿cuántos accesos fallidos?

    !!! tip "Piezas habituales":

    - `grep` (filtrar)
- `sort` (ordenar)
- `uniq -c` (contar repetidos)
- `cut` (sacar columnas)
- `wc -l` (contar líneas)
- `head`/`tail` (quedarse con el principio o el final).

    Procesos, servicios y programas¶

    Orden Hace
    ps aux, htop Ver procesos
    kill PID Terminar un proceso
    systemctl status ssh Estado de un servicio
    systemctl start/stop/restart ssh Controlar un servicio
    sudo apt update Actualizar la lista de programas
    sudo apt install tree Instalar un programa
    tar -czf copia.tar.gz carpeta Comprimir

    No hay que saberlo de memoria

    No hace falta memorizar todo esto. Hace falta saber que existe y cómo preguntar (man, --help). El resto se aprende usándolo.

    De aquí en adelante opcionales, pero tienes que saber que...

    Un script es un fichero con órdenes que se ejecutan una detrás de otra. Siempre empieza con #!/bin/bash y necesita permiso de ejecución.

    • AC 0175. info.sh: un script que muestre tu usuario, el nombre del equipo, la fecha, cuánto tiempo lleva encendido y el espacio libre del disco. Hazlo ejecutable y pruébalo.
    • AC 0176. copia.sh: un script que cree en ~/copias un comprimido de ~/practica cuyo nombre incluya la fecha de hoy (por ejemplo practica-2026-10-05.tar.gz).
    • AC 0177. saluda.sh: un script que reciba un nombre al ejecutarlo (./saluda.sh Ana) y salude. Si no se le pasa ningún nombre, debe explicar cómo se usa.

    • AC 0178. seguridad.sh: un script que, a partir de acceso.log, muestre este informe:

      Accesos correctos: 6
Accesos fallidos: 9
IP con más fallos: 10.0.0.66 (6 intentos)

    • AC 0179. Programa copia.sh para que se ejecute todos los días a las 22:00 con crontab -e.
